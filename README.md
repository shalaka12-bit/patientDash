## 🚀 Setup Instructions

### Step 1: Install Flutter
```bash
flutter --version   # should be 3.x or above
```

### Step 2: Create Firebase Project
1. Go to [https://console.firebase.google.com](https://console.firebase.google.com)
2. Create a new project (e.g. `medicare-emergency`)
3. Enable:
   - **Authentication** → Email/Password
   - **Firestore Database** → Start in test mode
   - **Storage** → Start in test mode

### Step 3: Connect Firebase to Flutter
```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# From inside the project folder:
flutterfire configure
```
This auto-generates `lib/firebase_options.dart` with your real credentials.

### Step 4: Install dependencies
```bash
flutter pub get
```

### Step 5: Add Google Maps API Key

**Android** — `android/app/src/main/AndroidManifest.xml`:
```xml
<meta-data
  android:name="com.google.android.geo.API_KEY"
  android:value="YOUR_GOOGLE_MAPS_API_KEY"/>
```

**iOS** — `ios/Runner/AppDelegate.swift`:
```swift
GMSServices.provideAPIKey("YOUR_GOOGLE_MAPS_API_KEY")
```

Get your key at: [https://console.cloud.google.com](https://console.cloud.google.com) → Maps SDK for Android/iOS

### Step 6: Add Permissions

**Android** — `android/app/src/main/AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
```

**iOS** — `ios/Runner/Info.plist`:
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>We need your location to find nearby hospitals.</string>
<key>NSLocationAlwaysUsageDescription</key>
<string>We need your location for emergency services.</string>
```

### Step 7: Seed Hospitals into Firestore
```bash
cd patient_emergency_app
npm install firebase-admin
# Download serviceAccountKey.json from Firebase Console → Project Settings → Service Accounts
node seed_hospitals.js
```

### Step 8: Deploy Firestore Rules
```bash
firebase deploy --only firestore:rules
```

### Step 9: Run the app
```bash
flutter run
```

## 🔐 Admin Access

The Admin Panel (`admin_panel_screen.dart`) should be:
- A **separate Flutter app** for hospital staff, OR
- Protected by Firebase Custom Claims (`admin: true` token)

To set admin claim via Firebase Admin SDK (Node.js):
```javascript
admin.auth().setCustomUserClaims(uid, { admin: true });
```
